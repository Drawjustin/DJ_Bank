# DJ Link 프론트엔드 (피그마 01~07 화면)

피그마 `DJ_LINK › WEHAGO 화면`의 01~07 프레임을 React(Vite)로 옮긴 시연용 화면입니다.
1920px 캔버스를 브라우저 폭에 맞춰 통째로 확대·축소합니다.

## 실행
```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

## 화면 흐름
| 주소 | 화면 | 동작 |
|---|---|---|
| `#/` | 01 랜딩 | 상단 `로그인`·`회원가입` → 02 |
| `#/login` | 02 로그인 | `로그인` → 03 (입력값은 저장·전송하지 않음) |
| `#/main?popup=news` | 03 메인 + 소식 팝업 | `X`·`닫기` → 04, 체크박스로 숨김 기간 저장 |
| `#/main` | 04 메인 대시보드 | 2.5초 뒤 정책자금 알림이 도착하며 07로 바뀜, `DJ Bank` 타일 → 05 |
| `#/main?alert=1` | 07 메인 + 정책자금 알림 | 알림 바 `확인하기`·`맞춤 공고 보기`·DJ Bank 배지 → DJ Bank |
| `#/djbank` | 05 출시 팝업 → 06 DJ Bank 홈 | 처음 들어갈 때만 팝업. `?popup=launch` 강제 표시, `?popup=none` 숨김 |

녹화할 때는 위 주소로 원하는 상태를 바로 열 수 있습니다.

## 구조
- `src/ui.tsx` 1920 캔버스 스케일러, 절대 배치 박스·텍스트·로고 공용 컴포넌트
- `src/components/` 상단 바, AI WE봇 플로팅
- `src/screens/` 화면별 컴포넌트. `LandingFigma.tsx`는 피그마 디자인 코드를 변환한 **자동 생성 파일**
- `src/assets/` 피그마에서 내보낸 SVG·PNG
- `src/data/demo.ts` 07의 정책자금 숫자(지금은 시안 값, 이후 API로 교체)

## 알아둘 점
- 이미지 자리(일러스트·3D 아이콘)는 피그마에도 실제 이미지가 없어 색 박스로 둡니다. 04·06 화면에서는 "IMG ·" 안내 문구를 뺐습니다.
- 모든 화면 왼쪽 아래에 "프로토타입 · 시연용" 표시가 있습니다(실제 서비스로 오인 방지). 녹화 때 가리고 싶으면 `src/main.tsx`에서 지우면 됩니다.
